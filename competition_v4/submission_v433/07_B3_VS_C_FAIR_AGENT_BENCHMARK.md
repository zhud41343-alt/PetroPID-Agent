# 07 · 强单体基线（B3 同等回退）vs 五阶段协作（C）公平配对对照报告

> **实验脚本**：[07_agents/v434_fair_comparison.py](../../07_agents/v434_fair_comparison.py)  
> **逐例原始数据**：[b3_vs_c_paired_trials.json](./b3_vs_c_paired_trials.json)（24 组配对 = 48 条逐例记录，覆盖 6 个代表回路 × 4 类场景）  
> **安全边界**：全部离线仿真（`PETROPID_LLM_DISABLE_DOTENV=1`），`deployment_authorized=false`。

---

## 1. 为什么要补做 B3 强单体对照？

在 V4.3.3 的 144 次模块消融中，五阶段 `C` 达到 `24/24 (100%)`，紧凑单体 `B2` 为 `23/24 (95.83%)`——这 1 例差异发生在收紧约束（`Ms ≤ 1.65`）场景，原因是 `B2` 仅验证了均衡候选，而 `C` 自动回退到保守候选。

为了杜绝“把保守回退收益错误归因给多智能体”，本实验构建 **B3 强单体基线（`B3_strong_monolithic_with_fallback`）**：与五阶段 `C` 共享**完全相同的诊断/辨识/整定工具、相同的候选顺序（`balanced → conservative`）、相同的 11 项硬约束、相同的重试、相同的 SHA-256 缓存、紧凑上下文以及同一套 `verify_audit_record()` 审计校验**，在 4 类场景（正常、首调超时、重复调用、收紧 `Ms ≤ 1.65` 触发保守回退）下开展配对实验。

| 评价维度（每组 24 次配对试验） | B3 强单体（同等回退/重试/缓存/审计） | C 五阶段黑板协作（PetroPID） | 差异与归因结论 |
| :--- | :---: | :---: | :--- |
| **独立决策正确率** | **24/24 (100.0%)** | **24/24 (100.0%)** | **平手（TIE）**：原 `24/24 vs 23/24` 的 1 例优势来自**保守回退机制**，而非单纯增加 Agent 数量 |
| **首调超时故障恢复率** | **100.0%** (6/6) | **100.0%** (6/6) | **平手**：容错恢复收益归因于**重试机制** |
| **重复调用防重拦截** | **6 次** | **6 次** | **平手**：防重收益归因于 **SHA-256 幂等缓存** |
| **实际工具执行总次数** | 71 次 | 74 次 | 相近（差异仅 3 次，均处于同类量级） |
| **配对输入证据哈希一致率** | **100.0%** | **100.0%** | 每组配对使用同一可观测时序、控制配置与 V4.3.3 profile，原始 JSON 逐例保存两侧哈希 |
| **`verify_audit_record()` 审计通过率** | **100.0%** (24/24) | **100.0%** (24/24) | **平手**：SHA-256 摘要完整性校验能力完全等价 |
| **独立阶段角色隔离与失败阶段定位率** | **0.0%**（单协调器汇总 1 条 trace） | **100.0%**（2–5 个独立阶段角色 trace） | **核心架构差异**：C 将诊断、辨识、整定、安全校验与独立审批拆分为独立阶段与结构化黑板交接，工程师与自动审计器可直接定位具体失败阶段与责任边界 |
| **平均序列化交接体量** | 171.5 B | 2,683.5 B | B3 仅存极简单体状态；C 保留各阶段完整结构化交接黑板（相比原始时序 `15,023 B` 仍压缩约 `82.1%`） |
| **延迟 P50 / P95** | **159.82 ms / 318.56 ms** | **223.51 ms / 334.90 ms** | C 的 P50 编排开销为 `+63.69 ms`，P95 增加 `16.34 ms`。在石化秒级/分钟级过程控制离线复核场景仍处于可接受量级 |

## 3. 清晰的模块归因表（答辩可直接引用）

- **决策恢复（收紧约束 `23/24 → 24/24`）** → 归因于 **多策略保守回退机制**；
- **瞬态超时恢复（`0% → 100%`）** → 归因于 **自动重试机制**；
- **重复调用消除（`6/6` 拦截）** → 归因于 **SHA-256 幂等缓存**；
- **交接体量压缩（`15,023 B → 2,683.5 B`）** → 归因于 **结构化紧凑状态黑板**；
- **五阶段多智能体架构的真实增量** → 在不牺牲决策正确率、增加 `63.69 ms` P50 编排延迟的前提下，提供 **100% 阶段职责隔离（计算与审批分离）与失败阶段精确溯源**，满足石化 MOC 工程复核对“谁诊断、谁辨识、谁整定、谁独立否决”的可审计治理要求。
