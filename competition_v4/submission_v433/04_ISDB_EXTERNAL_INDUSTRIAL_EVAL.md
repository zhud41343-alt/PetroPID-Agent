# 04 · 外部公开真实工业控制回路数据只读泛化评估（ISDB · 三方法横向对照与独立审计核验）

> **评估原则**：严格遵循「**冻结 V4.3.3 后端模型、零阈值调参、不挑样本、不隐藏失败案例、严格区分标签置信度与门禁边界**」的科研规范。本实验未修改任何 V4.3.3 后端诊断、辨识、安全约束或决策代码，仅通过独立只读脚本 [isdb_external_eval.py](../../07_agents/isdb_external_eval.py) 直接评估外部真实工业历史数据，并与两类经典量纲无关工业粘滞检测方法开展横向对照。

---

## 1. 数据来源、复现元数据与评测边界声明

- **数据集**：**International Stiction Data Base（ISDB, `isdb10.mat`）**，来源于 Jelali & Huang 编著《*Detection and Diagnosis of Stiction in Control Loops: State of the Art and Advanced Methods*》（Springer, 2010），官方下载源：`https://sites.ualberta.ca/~bhuang/ISDB.zip`。
- **复现元数据**：
  - 源文件：`isdb10.mat`（SHA-256: `4dd329b5af3f9bd6e9070bce3fd46e001bb763a21c9fb8be026571b9d364e7df`）；
  - 数据截取规则：对长度超过 1500 点的长时序统一截取**前 1500 个样本**（与在线 CSV 接口长度包络对齐，JSON 中同时记录每条回路的 `n_samples_original` 与 `n_samples_evaluated`）；
  - 运行环境：`Python 3.11.6`、`NumPy 2.4.4`、`SciPy 1.17.1`、`PETROPID_LLM_DISABLE_DOTENV=1`（确定性离线模式）；
  - 非再分发声明：遵循原数据库学术研究规范，仓库**不再分发 `isdb10.mat`**，仅归档只读脚本（`07_agents/isdb_external_eval.py`）、完整逐回路原始输出 JSON（`isdb_external_raw_results.json`，已原生统一输出 5 组标签与三方法指标）与本报告。
- **严格可评价边界**：
  - **可评价**：① 冻结诊断器与两类经典量纲无关方法在真实工业历史数据上的横向对照表现；② 冻结流水线在 `has_known_plant_truth=False`（未知过程真值）条件下的**预设安全门禁执行一致性**；③ 对 76 条运行记录执行**独立二次 `verify_audit_record()` 密码学核验**；
  - **不可宣称**：ISDB 为离线历史采集数据，**不能**据此宣称已验证新 PID 参数在真实炼厂的闭环改善效果；亦**不能**将未知过程真值门禁下的 `0/76` 放行解释为真实工业闭环安全误放行率为零的独立统计证明。

## 2. 样本标签严格 5 分层（脚本与 JSON 原生对齐）

严格依据 `isdb10.mat` 官方 `BriefComments` 与 `Comments` 将全部 76 个化工/炼油回路（`CHEM-01..76`，0 例排除）拆分为 **5 组**：

| 分组 | 回路数 | 标注依据 |
| :--- | :---: | :--- |
| `CONFIRMED_STICTION`（明确粘滞正样本） | 10 | 注释明确含 `"Has a stiction problem"` / `"Has valve stiction problem"`（无 `likely`） |
| `EXPLICIT_NO_STICTION`（明确非粘滞严格负样本） | **6** | `BriefComments` 明确标注 `no stiction`（`CHEM-71 ~ CHEM-76`） |
| `OTHER_FAULT_UNCONFIRMED_STICTION`（其他故障/粘滞未排除启发式负样本） | **12** | 注释含 `tuning issue` / `quantisation` / `faulty steam sensor` / `disturbance (likely)` 等，**仅作探索性对照** |
| `LIKELY_STICTION`（疑似粘滞） | 9 | 标注 `"with stiction (likely)"` |
| `UNLABELED_REFINERY`（无显式粘滞标签炼厂回路） | 39 | 东南亚炼油厂与分离单元真实回路（仅评估门禁与审计一致性，不计入混淆矩阵） |

## 3. 实测结果

### 3.1 未知过程真值安全门禁与独立二次审计核验（全量 76 回路）

> **边界说明**：脚本对全部 76 条外部历史回路设置 `has_known_plant_truth = False`，冻结决策引擎规定缺少已知过程真值时不得输出仿真验证通过的参数变更结论。下表验证的是**预设未知真值安全门禁执行一致性**与**独立二次审计校验完整性**，**不构成**真实工业闭环整定安全性的独立统计证明。

| 门禁与审计指标（全量 76 个外部工业回路） | 实测结果 | 核验方式 |
| :--- | :---: | :--- |
| 输出参数变更放行结论 (`SIMULATION_VALIDATED_PENDING_ENGINEERING_REVIEW`) | **0 / 76 (0.0%)** | 预设未知过程真值门禁在 76 条外部输入上全部生效 |
| `MODEL_VALIDATION_FAILED` / `VALVE_MAINTENANCE_REQUIRED` / `HEALTHY_NO_CHANGE` | **37 / 33 / 6** | 全部保持原 DCS 参数 |
| `deployment_authorized = true` | **0 / 76 (0.0%)** | 严守隔离离线边界 |
| 流水线返回 `audit_status = PASS` | **76 / 76 (100.0%)** | 流水线输出字段统计 |
| **二次 `verify_audit_record(wf)` 完整性核验通过** | **76 / 76 (100.0%)** | **在流水线外部逐条再次调用同一 `verify_audit_record()` 核验，全部 PASS（属调用层二次完整性核验，非第三方密码学证明）** |

### 3.2 三方法横向对比：冻结 V4.3.3 启发式 vs 基于 Horch 思想的互相关与归一化滞环特征（零调参）

为探索冻结轻量时域诊断器在真实炼厂数据上的误报特征，我们在同一 76 条 ISDB 回路上引入两类基于经典文献思想的量纲无关启发式特征做横向对照（所有方法均未在 ISDB 上做拟合或交叉验证调参）：

| 检测方法 | 严格 16 回路 (`10` 粘滞 vs `6` 明确 `no stiction`)<br>TP/FN · FP/TN · Prec / Rec / **F1** | 启发式 28 回路 (`10` 粘滞 vs `18` 非粘滞)<br>TP/FN · FP/TN · Prec / Rec / **F1** |
| :--- | :---: | :---: |
| **方法 1：V4.3.3 冻结启发式 (`diagnose_loop`)** | `5/5 · 4/2` · 55.56% / 50.00% / **52.63%** | `5/5 · 10/8` · 33.33% / 50.00% / **40.00%** |
| **方法 2：基于 Horch (1999) 思想的互相关奇偶特征启发式实现** | `5/5 · 2/4` · **71.43%** / 50.00% / **58.82%** | `5/5 · 5/13` · **50.00%** / 50.00% / **50.00%** |
| **方法 3：量纲归一化 PV-OP 滞环面积 + 平顶粘滞比** | `3/7 · 0/6` · **100.00%** / 30.00% / **46.15%** | `3/7 · 3/15` · **50.00%** / 30.00% / **37.50%** |

- **异常检出率（非 `NORMAL`）**：冻结 V4.3.3 在 10 条明确粘滞回路上检出异常 **9/10（90.0%）**，在 9 条疑似粘滞回路上检出异常 **8/9（88.9%）**。

## 4. 严谨科研结论与后续演进路径

1. **特征与尺度处理的影响（谨慎归因）**：在当前 ISDB 子集和预设判别阈值下，两种量纲归一化或基于 Horch 思想的互相关启发式方法减少了部分粘滞误报（严格负样本组 `FP` 由 `4` 降至 `2` 或 `0`），表明特征定义及尺度处理可能影响跨域诊断表现；但由于三种方法同时改变了特征、判别机制与阈值（且归一化面积法召回率降至 `30%`），**尚无法独立确认量纲敏感性是主要因果因素**。
2. **真实炼厂部署演进方向**：现有单特征启发式在恒定设定值、高噪声与强耦合炼厂数据上召回表现有限，面向未来真实炼厂上线，应引入多特征融合或视觉相图分类器与本系统的确定性安全门控结合，并在目标装置历史库上完成标定与离线影子运行验证。
3. **安全门禁与审计一致性保持不变**：在 76 条真实外部工业历史输入上，无论上游粘滞诊断是否命中，下游未知过程真值门禁与二次 `verify_audit_record()` 核验均保持 `0/76` 参数放行与 `76/76` 完整性核验通过。
