# 04 · 外部公开真实工业控制回路数据只读泛化评估（ISDB · 零调参）

> **评估原则**：严格遵循「**冻结模型、零阈值调参、不挑样本、不隐藏失败案例、不篡改口径**」的科研规范。本实验未修改任何 V4.3.3 后端诊断、辨识、安全约束或决策代码，仅通过独立只读脚本 [isdb_external_eval.py](../../07_agents/isdb_external_eval.py) 直接评估真实工业数据。

---

## 1. 数据来源、许可与评测边界声明

- **数据集**：**International Stiction Data Base（ISDB, `isdb10.mat`）**，来源于 Jelali & Huang 编著《*Detection and Diagnosis of Stiction in Control Loops: State of the Art and Advanced Methods*》（Springer, 2010），官方下载源：`https://sites.ualberta.ca/~bhuang/ISDB.zip`（阿尔伯塔大学 Biao Huang 教授主页）。
- **知识产权与非再分发声明**：遵循原数据库学术研究用途规范，本仓库**不再分发原始 `isdb10.mat` 文件**；仅归档独立只读评测脚本（`07_agents/isdb_external_eval.py`）、完整逐回路原始输出 JSON（`isdb_external_raw_results.json`）与本分析报告，任何审稿人下载官方 `ISDB.zip` 即可 100% 复现。
- **评测对象**：化工与炼油板块全部 **76 个真实工业控制回路**（`cdata.chemicals.loop1 ~ loop76`，涵盖东南亚炼油厂、炼厂分离单元、精馏塔底液位/流量/压力/温度控制回路），排除数 `0`（76/76 全部满足 `n ≥ 100` 且无 NaN/Inf）。
- **严格可评价边界**：
  - **可评价**：① 冻结诊断器在真实工业数据上的**异常检出能力**与**二分类粘滞识别能力（零调参）**；② 冻结 `C-000` 模型置信门控与 9 态 Fail-Closed 引擎在未知真实工业回路上的**保守安全防误放行能力**；③ 全量审计记录完整性。
  - **不可宣称**：ISDB 为离线历史开/闭环采集数据（无真实工厂闭环回写条件），**绝不能**据此宣称已验证新 PID 参数在真实炼厂中的闭环改善效果；亦不能用仅含粘滞标注的数据集宣称验证了全部 6 类故障诊断准确率。

## 2. 样本标签分层与实测结果

严格依据 `isdb10.mat` 官方 `BriefComments` 与 `Comments` 将 76 个真实化工/炼油回路分为 4 组：

| 分组 | 回路数 | 说明 |
| :--- | :---: | :--- |
| `CONFIRMED_STICTION`（明确确认粘滞） | 10 | 明确标注 `"Has a stiction problem"` / `"Has valve stiction problem"`（无 `likely`） |
| `LIKELY_STICTION`（疑似粘滞） | 9 | 标注 `"with stiction (likely)"` |
| `CONFIRMED_NON_STICTION`（明确非粘滞） | 18 | 明确标注 `"no stiction"`、`tuning issue`、`quantisation`、`faulty steam sensor`、`disturbance` |
| `UNLABELED_REFINERY`（无显式粘滞标签炼厂回路） | 39 | 东南亚炼油厂与分离单元真实回路（仅评估 Fail-Closed 安全行为，不计入粘滞二分类混淆矩阵） |
| **合计** | **76** | **0 例排除，0 例运行崩溃，76/76 审计验真 PASS** |

### 2.1 核心发现一：未知真实工业回路上的 Fail-Closed 安全防线（76/76 零盲目放行）

| 安全指标（全量 76 个真实工业回路） | 实测结果 | 工程解读 |
| :--- | :---: | :--- |
| 盲目输出“仿真通过待整定” (`SIMULATION_VALIDATED_PENDING_ENGINEERING_REVIEW`) | **0 / 76 (0.0%)** | 面对无已知对象真值、无充分阶跃激励的真实历史数据，系统**零次盲目推荐 PID 变更** |
| 模型门控安全拦截 (`MODEL_VALIDATION_FAILED`) | **37 / 76 (48.7%)** | 真实炼厂恒定设定值/强扰动数据触发 `C-000` 门控拦截 |
| 建议仪表/阀检 (`VALVE_MAINTENANCE_REQUIRED`) | **33 / 76 (43.4%)** | 提示现场排查执行机构而非盲目调 PID |
| 健康保持 (`HEALTHY_NO_CHANGE`) | **6 / 76 (7.9%)** | 保持原 DCS 参数 |
| `deployment_authorized = true` | **0 / 76 (0.0%)** | 100% 严守离线隔离安全边界 |
| `verify_audit_record()` 审计验真通过 | **76 / 76 (100.0%)** | 全部 76 次外部真实数据运行均生成完整可核验审计记录 |

### 2.2 核心发现二：冻结模型零调参粘滞诊断能力（诚实暴露跨域落差）

在 **28 个明确标注回路**（10 确认粘滞 + 18 确认非粘滞）上的二分类粘滞混淆矩阵：

| 真实标签 \ 冻结模型预测 | 预测 `VALVE_STICTION` | 预测非粘滞（其他异常或正常） | 合计 |
| :--- | :---: | :---: | :---: |
| **确认粘滞 (`CONFIRMED_STICTION`)** | **TP = 5** | **FN = 5** | 10 |
| **确认非粘滞 (`CONFIRMED_NON_STICTION`)** | **FP = 10** | **TN = 8** | 18 |

- **严格二分类粘滞指标（零调参）**：Recall = **50.0% (5/10)**，Precision = **33.33% (5/15)**，F1 = **40.0%**；
- **异常检出率（非 `NORMAL`）**：确认粘滞组 **9/10（90.0%）** 被检出异常；疑似粘滞组（`n=9`）中 **6/9（66.7%）** 判为 `VALVE_STICTION`、**8/9（88.9%）** 检出异常（合并 19 个粘滞/疑似粘滞回路：异常检出 **17/19 = 89.5%**，直接命中粘滞 **11/19 = 57.9%**）。

## 3. 失败案例根因分析与科研启示

本实验**如实揭示了合成仿真基准（40 SOPDT 95%）与真实工业现场数据（ISDB 粘滞 Recall 50% / Precision 33.3%）之间的显著域迁移落差**：
1. **假阴性（FN=5）成因**：部分真实化工回路（如恒定设定值 `ΔSP=0`、低幅值粘滞或高采样频次下的微弱死区）缺乏显著阶跃变化，当前基于固定窗口与时域滞环启发式的 `stiction_index` 阈值在未适配工况量纲时偏保守，将其归类为外扰或模型失配（但仍被上游检出异常并触发 Fail-Closed 拒批）。
2. **假阳性（FP=10）成因**：真实炼厂回路中的**传感器量化台阶（如 `CHEM-03`）、循环物料耦合振荡（`CHEM-71..76`）及强外部周期扰动**在 PV-OP 平面上也会呈现近似椭圆/阶梯滞环，导致单靠当前轻量时域特征容易误报粘滞。
3. **关键工程结论**：
   - **安全架构价值得到独立外部数据印证**：即便上游诊断器在零调参真实工业数据上存在明显跨域误判（F1=40%），下游 `C-000` 模型独立验证门控与 `FinalDecisionEngine` 仍实现了 **0/76 盲目 PID 放行**，证明系统安全边界**不依赖理想诊断假设**；
   - **后续演进方向明确**：若面向真实炼厂上线，应将当前轻量时域粘滞特征升级为量纲无关的双谱/互相关或视觉相图分类器（如行业最新 StictionGPT 路线），并在目标装置历史库上完成阈值标定与影子运行验证。
