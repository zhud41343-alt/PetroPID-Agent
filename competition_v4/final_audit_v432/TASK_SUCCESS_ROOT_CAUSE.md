# 05 · 30 回路任务成功率 80% 物理根因分析（P1-01）

- **独立全任务精确匹配率**：**`24/30 = 80.0%`**（未达官方 90% 口径，如实保留）；保守安全决策 `30/30 = 100%`；危险误放行 `0%`。
- **6 个失败回路 (`LOOP-012..017`) 逐项根因实测**：
  - 训练集 `train_r2 = 0.966–0.972`，辨识出的 `K_hat / tau_hat` 与真值误差 `<5%`；
  - 失败根因为后 35% 留出验证段存在一致的 **`+0.31～+0.32` 未测负载阶跃偏移**，迟缓控制器无法在验证窗内消除偏置，导致 `val_r2 = 0.51–0.60 < 0.80`；
  - **结论**：属外部未测扰动导致的验证集偏置（类别 4），工程上不应强行推荐参数，坚持 Fail-Closed 拒绝。
