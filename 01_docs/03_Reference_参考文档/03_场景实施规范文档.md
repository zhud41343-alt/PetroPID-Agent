# 场景实施规范文档（Reference 03 · V4.0）

## 1. 安全边界与数据脱敏红线
- 本系统所有运行与测试**仅限本地机理仿真、隔离数字孪生沙盒或脱敏历史数据**，严禁直连或写入真实 DCS/PLC；
- `deployment_authorized` 在代码中硬编码为 `False`，任何推荐参数仅进入 `SIMULATION_VALIDATED_PENDING_ENGINEERING_REVIEW` 人工复核队列。

## 2. 11 项确定性安全硬约束红线（`04_algorithms/petro_pid/safety_verifier.py`）
| 约束编号 | 规则项 | 强制红线 | 违规处置 |
| :--- | :--- | :--- | :--- |
| **`C-000`** | **FOPDT 模型独立验证可信度** | 留出 35% 验证段 `R² ≥ 0.80` 且 `Fit ≥ 85%` | 100% 拦截 (`MODEL_VALIDATION_FAILED`) |
| `C-001`–`C-003` | PID 参数物理边界 | `Kc ∈ [0.05, 8.0]`, `Ti ∈ [1.5, 200]s`, `Td ∈ [0, 20]s` | 100% 拦截 (`SAFETY_REJECTED`) |
| `C-004`–`C-006` | 频域鲁棒稳定裕度 | `GM ≥ 1.8`, `PM ≥ 35°`, `Ms ≤ 2.2` | 100% 拦截 + 触发保守回退 |
| `C-007` | **标称工况**阶跃超调红线 | `Nominal Overshoot ≤ 18%` | 100% 拦截 + 触发保守回退 |
| `C-008`–`C-009` | 调节阀保护 | 饱和占比 `≤ 10%`，单步最大变化率 `≤ 10%/s` | 100% 拦截 |
| `C-010` | **5 工况跨边界鲁棒性** | 5 工况 100% 闭环稳定 + 通过率 `≥ 80%`（**扰动工况专用红线：`超调 ≤ 25%`, `OI ≤ 0.42`**） | 100% 拦截并列出 `failed_regimes` |

## 3. 人工投运四步审批规范
`仿真校验通过 (SIMULATION_VALIDATED_PENDING_ENGINEERING_REVIEW)` → `导出带 run_id 与 SHA-256 哈希的 DCS 安全复核单` → `自控工程师与工艺主任双签审批` → `DCS 人工无扰切换 (Bumpless Transfer) 与 24h 监护`。
