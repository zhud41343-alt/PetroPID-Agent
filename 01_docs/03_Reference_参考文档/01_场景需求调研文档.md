# 场景需求调研文档（Reference 01）

## 1. 石化装置 PID 控制现状调研
调研覆盖常减压精馏塔 (CDU)、催化裂化 (FCC)、乙烯裂解炉、连续搅拌反应釜 (CSTR) 与加氢精制五大核心石化装置的典型温度 (TIC)、压力 (PIC)、流量 (FIC)、液位 (LIC) 控制回路，梳理出四大刚性业务需求：
1. **自动化巡检与根因解耦**：需自动区分参数激进、响应迟缓、调节阀机械粘滞、换炼工况失配及上游外部扰动，避免错误调参；
2. **闭环非侵入式模型辨识**：利用历史 DCS 时序完成 FOPDT 过程辨识，并严格在独立留出验证时段保障 `≥ 90%` 预测准确率；
3. **100% 确定性安全护栏**：任何推荐 PID 参数下发前必须通过参数边界、频域幅值/相位裕度、灵敏度峰 Ms、阀门保护及 5 工况鲁棒性校验；
4. **多智能体工程治理**：解决多智能体协作中的工具重复调用、长时序上下文膨胀与校验失败无法及时汇总问题。

## 2. 功能与非功能需求矩阵
| 需求编号 | 需求类别 | 具体要求 | 验收指标 |
| :--- | :--- | :--- | :--- |

| FR-04 | 安全校验 | 10 项硬约束 + 5 工况跨边界验证 | 覆盖率 100%、标记率 100%、多工况 ≥ 85% |
| NFR-01 | 响应时效 | 单回路端到端协同任务耗时 | ≤ 5 分钟（实测 < 1 秒） |
| NFR-02 | 生态兼容 | 对齐华为 openJiuwen、MCP 2024-11-05 与 OWL/RDF | 全部联调测试通过 |
