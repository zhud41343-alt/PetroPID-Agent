# 技术参考资料与核心控制公式推导（Reference 04）

## 1. 一阶加纯滞后过程模型 (FOPDT)
$$G(s) = \frac{K_p e^{-\theta s}}{\tau s + 1}$$
其中 $K_p$ 为稳态增益，$\tau$ 为时间常数，$\theta$ 为纯滞后时间。离散化采用零阶保持精确递推：$y(k+1) = e^{-\Delta t / \tau} y(k) + K_p (1 - e^{-\Delta t / \tau}) u(k - d)$。

## 2. Harris 最小方差控制性能指数
对控制偏差 $e(t) = SP(t) - PV(t)$ 拟合自回归模型 $AR(p)$，基于滞后步数 $d$ 展开前 $d$ 步脉冲响应权重 $\psi_0, \dots, \psi_{d-1}$：
$$\hat{\sigma}_{mv}^2 = \left(\sum_{i=0}^{d-1} \psi_i^2\right) \sigma_a^2, \quad \eta_{\text{Harris}} = \text{clip}\left(\frac{\hat{\sigma}_{mv}^2}{\sigma_e^2},\ 0,\ 1\right)$$

## 3. Choudhury 双参数阀门粘滞模型
由静摩擦带 $S$（deadband + stickband）与滑跳量 $J$（slip-jump）描述。当控制器指令方向反转时阀芯卡滞，直到累计指令变化量 $|\Delta u| \ge S$ 后发生阶跃滑移 $v(t) = u(t) - \text{sign}(\Delta u)\frac{S-J}{2}$。

## 4. Skogestad SIMC 解析整定与频域稳定裕度
- **SIMC 基线**：选取闭环时间常数 $\tau_c = \max(\theta, 0.25\tau)$，则 $K_c = \frac{\tau}{K_p(\tau_c + \theta)}$，$T_i = \min(\tau, 4(\tau_c + \theta))$。
- **频域鲁棒性**：沿频率轴计算开环传递函数 $L(j\omega) = C(j\omega)G(j\omega)$，精确求解幅值裕度 $GM$、相位裕度 $PM$ 及最大灵敏度峰 $M_s = \max_\omega \left|\frac{1}{1+L(j\omega)}\right|$。
