## 3. 核心 API 与审计导出入口
- `POST /api/run/{loop_id}`：执行 5-Agent + `FinalDecisionEngine` 闭环并登记不可变 `run_id`
- `POST /api/sandbox` & `POST /api/upload_csv`：实时压力测试与安全限流 CSV 上传诊断（限 512 KB / 5000 行 / 拒 NaN 与乱序）
- `GET /api/approval/{loop_id}?run_id=...`：生成绑定同一 `run_id` 的可打印《DCS 安全复核单》
- `GET /api/export_bundle/{loop_id}?run_id=...`：导出含 `input_hash` / `output_hash` / 11 项约束与全链路 Trace 的可审计 JSON 包
- `POST /mcp/rpc`：标准 JSON-RPC 2.0 MCP HTTP 入口
