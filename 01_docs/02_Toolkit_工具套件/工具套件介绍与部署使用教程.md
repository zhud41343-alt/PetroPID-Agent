## 3. 核心 API 与审计导出入口
- `GET /healthz` / `GET /healthz?probe_llm=true`：运行版本、40 位 Git SHA、DeepSeek 探针与 `deployment_authorized=false` 校验
- `POST /api/run/{loop_id}`：执行 5-Agent + `FinalDecisionEngine` 闭环并登记全局唯一 `run_id`
- `POST /api/sandbox` & `POST /api/upload_csv`：压力沙盒与安全限流 CSV 上传（限 512 KB / 5000 行，缺列/NaN 返回 HTTP 400 Fail-Closed 拦截）
- `GET /api/approval/{loop_id}?run_id=...`：导出绑定 `run_id` 与 SHA-256 摘要的可打印《DCS 安全复核单》（跨回路越权返回 HTTP 409）
- `GET /api/export_bundle/{loop_id}?run_id=...`：导出含 `input_hash` / `output_hash` / `record_digest_sha256` / 11 项约束与全链路 Trace 的 JSON 审计包
- `POST /mcp/rpc`：标准 JSON-RPC 2.0 MCP HTTP 入口
