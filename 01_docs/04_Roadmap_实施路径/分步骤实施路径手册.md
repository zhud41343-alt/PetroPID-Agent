# 分步骤实施路径手册（Roadmap）

本手册面向石化企业自控与数字化团队，给出 **6 阶段可落地实施路线图**（单套装置 4–6 周完成试点上线）：

| 阶段 | 实施周期 | 核心任务 | 对应本项目交付资产 | 验收里程碑 |
| :---: | :---: | :--- | :--- | :--- |
| **Phase 1：数据接入与脱敏** | 第 1 周 | 对接 DCS/OPC-UA 历史库，执行 Hampel 去尖峰、插值与位号脱敏 | `02_datasets/` + `03_models/data_model/` | 清洗后数据完整率 ≥ 99.5%，零敏感信息泄露 |
| **Phase 2：领域建模与本体构建** | 第 2 周 | 导入 ISA-5.1 信息模型、知识三元组与 OWL/RDF 本体规则 | `03_models/{info,knowledge,ontology}_model/` | `validate_models.py` 100% 校验通过 |
| **Phase 3：控制算子与 Skill 封装** | 第 3 周 | 部署诊断/辨识/整定/安全校验算子并封装为幂等 Skill | `04_algorithms/` + `05_skills/` | 全部 `pytest` 单元测试通过 |
| **Phase 4：MCP 与多智能体编排** | 第 4 周 | 启动 MCP 服务，对接华为 `openJiuwen` 与昇腾 MindIE 大模型推理 | `06_mcp/` + `07_agents/` | MCP 8/8 联调通过，30 回路基准全部达标 |
| **Phase 5：离线影子验证** | 第 5 周 | 在 Web Demo 看板上以“只读影子模式”连续运行 7 天，人工复核推荐参数 | `08_demo_web/` | 专家认可率 ≥ 90%，安全违规 100% 拦截 |
| **Phase 6：DCS 灰度投运与推广** | 第 6 周+ | 优先对非关键液位/流量回路灰度下发，逐步推广至全厂核心塔器/反应釜 | 全套文档与审计台账 | 装置平稳率提升，形成全厂可复用智能体资产 |
