# 分步骤实施路径手册（Roadmap · V4.3.3 工业安全边界版）

本手册面向石化企业自控与数字化团队，给出 **6 阶段离线优先、人工审批兜底的可落地实施路线图**（全程严守不直接自动写回真实 DCS 的工业安全边界）：

| 阶段 | 实施周期 | 核心任务 | 对应本项目交付资产 | 验收里程碑 |
| :---: | :---: | :--- | :--- | :--- |
| **Phase 1：数据接入与脱敏** | 第 1 周 | 对接 DCS/OPC-UA 只读历史镜像库，执行去尖峰、插值与位号脱敏 | `02_datasets/` + `03_models/data_model/` | 清洗后数据完整率 ≥ 99.5%，零生产网写权限 |
| **Phase 2：领域建模与本体构建** | 第 2 周 | 导入 ISA-5.1 信息模型、22 条知识三元组与 116 条 OWL/RDF 本体规则 | `03_models/{info,knowledge,ontology}_model/` | `validate_models.py` 100% 校验通过 |
| **Phase 3：控制算子与 Skill 封装** | 第 3 周 | 部署诊断/65-35辨识/SIMC整定/11项硬约束算子并封装为幂等 Skill | `04_algorithms/` + `05_skills/` | `pytest` 安全/审计/负向测试全部通过 |
| **Phase 4：MCP 与多智能体编排** | 第 4 周 | 启动 MCP JSON-RPC 2.0 服务，配置 openJiuwen 适配层与离线规则降级 | `06_mcp/` + `07_agents/` | **MCP 14/14 联调通过**，30 回路保守安全决策 100%、危险误放行 0% |
| **Phase 5：离线影子验证（Shadow Mode）** | 第 5 周 | 在工业 HMI 工作站上对接历史镜像连续只读影子运行，针对目标装置标定粘滞阈值并核对 76+ 历史回路门禁表现 | `08_demo_web/` + `07_agents/isdb_external_eval.py` | 无未授权写入，Playwright E2E 0 JS 报错，工程师复核认可 |
| **Phase 6：MOC 双签人工投运** | 第 6 周+ | 经工艺与自控工程师按工厂既有 MOC（变更管理）流程双签审批《DCS 参数变更安全复核单》，由授权人员在 DCS 侧人工无扰切换 | `GET /api/approval/{loop_id}` + 全链路 SHA-256 审计包 | 全流程可追溯、可回滚，始终维持 `deployment_authorized=false` 辅助定位 |
