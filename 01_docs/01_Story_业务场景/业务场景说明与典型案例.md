# 业务场景 Story：石化复杂过程多智能体自适应 PID 诊断与整定 (V4.0)

## 1. 行业痛点与业务背景
一座千万吨级炼化一体化基地通常部署 **3,000–8,000 个 DCS PID 控制回路**，约 **30%–45%** 长期处于亚健康状态（参数激进振荡、响应迟缓、调节阀机械粘滞或换炼工况失配），带来四大工程难题：
1. **人工排查效率低**：依赖资深自控专家逐回路调曲线、做阶跃试验、手工试凑，单回路耗时 **2–4 小时**；
2. **错误调参安全风险高**：把“调节阀机械粘滞”或“上游周期性外部扰动”误当成“PID 参数问题”盲目调参，不仅无法消除振荡，还会加剧阀门磨损或导致抗扰性能恶化；
3. **模型不可靠导致推荐失真**：历史时序存在未测负载阶跃或激励不足时，辨识模型在独立验证时段失真，直接基于失效模型整定极易引发闭环失稳；
4. **多智能体工程治理缺失**：诊断、辨识、整定与安全校验之间易出现工具重复调用、600 点长时序上下文膨胀、以及大模型越权绕过安全门控等问题。

## 2. V4.0 解决方案：可信诊断 · 独立安全拒绝 · 全链路审计
**PetroPID-Agent V4.0** 构建了 **5-Agent 协同工作流 + 独立 `FinalDecisionEngine`（9 态固定优先级）+ MCP JSON-RPC 2.0 + OWL 本体推理** 的隔离仿真决策平台：
- **三权严格分离**：`candidate_eligible_for_review`（确定性门控）与 `engineering_approval_status`（人工复核状态）严格解耦，且 `deployment_authorized` 在隔离仿真环境中**硬编码永远为 `False`**，严禁未经审批写入真实 DCS；
- **独立模型门控 (`C-000`) + 10 项安全硬约束 (`C-001`–`C-010`)**：合计 11 项门控，100% 校验覆盖、100% 违规拦截；
- **显式双层超调红线**：标称工况 `≤ 18%`，5 组跨工况扰动专用红线 `≤ 25%, OI ≤ 0.42, 100% 闭环稳定`。

## 3. 四大典型工业案例（均可于 Web Demo 一键复现与导出 `run_id` 审计包）
1. **案例一 · 有效整定待复核**：催化裂化提升管温控 `TIC-201` (`LOOP-006`，激进振荡)
   - FOPDT 独立验证 Fit `98.64%`，通过全部 11 项安全硬约束与 5/5 多工况验证，IAE `10.83 → 0.47`、OI `1.00 → 0.04`，输出 `SIMULATION_VALIDATED_PENDING_ENGINEERING_REVIEW` 并生成可打印《DCS 安全复核单》。
2. **案例二 · 模型不可靠诚实拒绝**：常压塔底液位 `LIC-103` (`LOOP-012`，保守迟缓+未测负载阶跃)
   - 后 35% 留出验证段受未测负载偏移影响（$R^2=0.60 < 0.80$），`C-000` 模型门控精准拦截并返回 `MODEL_VALIDATION_FAILED`，保持原参数并提示施加安全阶跃激励后重辨识。
3. **案例三 · 机械故障拦截**：乙烯燃料气压力 `PIC-304` (`LOOP-020`，调节阀粘滞)
   - 结合滑跳加速度峰度与本体规则 `R-01` 精准识别粘滞（`SI=0.90`），拦截纯调参并返回 `VALVE_MAINTENANCE_REQUIRED`，派发仪表检维修建议。
4. **案例四 · 外部扰动性能门控拒绝**：常压燃料气压力 `PIC-108` (`LOOP-028`，上游压缩机周期脉动)
   - 仿真对照发现反馈调参使 IAE 从 `1.51` 略微恶化至 `1.55`，性能净改善门控自动拦截并返回 `PERFORMANCE_NOT_IMPROVED`，建议排查上游脉动源与前馈补偿。

## 4. 公平实验与量化收益（来自 `competition_v4/v4_experiments.json`）
- **危险误放行清零（5 阶段消融实测）**：在 25 个异常回路上，盲目使用传统 SIMC 会产生 **14 次危险误放行**，PetroPID V4.0 将其降至 **0 次**；
- **公平 SIMC 对照（11 个可整定回路）**：原 PID 平均 IAE `11.443` → 传统 SIMC `0.444` ($M_s=1.590$) → PetroPID V4.0 `0.458` (**$M_s=1.557$ 更优频域鲁棒性**)，OI 平均降低 **96.05%**、IAE 平均降低 **95.48%**；
- **独立二阶 SOPDT 泛化验证（12 个未见回路）**：**0 次危险误放行 (`0/12`)**，验证了跨模型结构的工程鲁棒性。
