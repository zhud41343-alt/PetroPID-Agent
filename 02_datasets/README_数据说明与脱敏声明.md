# 石油化工 PID 控制回路基准数据集说明与脱敏声明

## 1. 数据集概览
本数据集面向**第二届石油和化工行业人工智能创新大赛 · 智能体赛道（赛题 5：多智能体协作自适应 PID 控制回路诊断与智能整定）**构建，覆盖 **5 大典型石化核心装置**、**30 个标准控制回路**、**6 类典型健康与异常工况**，单回路采样周期 `dt = 1.0 s`，时长 `600 s`（共 18,000 条高质量时序记录）。

| 装置名称 | 涵盖回路类型 | 代表位号 |
| :--- | :--- | :--- |
| 常减压精馏塔 (CDU) | 温度 / 流量 / 液位 / 压力 | TIC-101, FIC-102, LIC-103, PIC-104, TIC-105, FIC-106, TIC-107, PIC-108 |
| 催化裂化装置 (FCC) | 温度 / 压力 / 流量 / 液位 | TIC-201, PIC-202, FIC-203, LIC-204, TIC-205, TIC-206 |
| 乙烯裂解炉 (Cracker) | 温度 / 流量 / 压力 | TIC-301, FIC-302, TIC-303, PIC-304, TIC-305, FIC-306 |
| 连续搅拌反应釜 (CSTR) | 温度 / 流量 / 液位 / 压力 | TIC-401, FIC-402, LIC-403, FIC-404, PIC-405 |
| 加氢精制装置 (Hydrotreater) | 温度 / 流量 / 压力 / 液位 | TIC-501, FIC-502, PIC-503, TIC-504, LIC-505 |

## 2. 异常类型标注分布
| 异常类别 (`anomaly_type`) | 数量 | 机理特征与工程含义 |
| :--- | :---: | :--- |
| `NORMAL` | 5 | 健康运行回路，Harris 指数高、无显著振荡与粘滞 |
| `AGGRESSIVE_TUNING` | 6 | 比例增益过高或积分时间过短导致强超调与高频振荡 |
| `SLUGGISH_TUNING` | 6 | 参数过于保守，设定值跟踪缓慢、残余偏差大 |
| `VALVE_STICTION` | 5 | Choudhury 双参数阀门粘滞-滑移模型，PV-OP 呈典型滞回环 |
| `MODEL_MISMATCH` | 5 | 原料切换或负荷漂移导致过程增益/纯滞后变化、原参数失配 |
| `EXTERNAL_DISTURBANCE` | 3 | 上游压机/泵组周期脉动耦合干扰 |

## 3. 目录结构与划分方式
- `raw/`：原始采集时序 CSV（含模拟工业 DCS 偶发野值尖峰与缺失点）。
- `processed/train/`（18 回路，60%）、`processed/val/`（6 回路，20%）、`processed/test/`（6 回路，20%）：经 `scripts/clean_and_split.py` 线性插值 + Hampel 中值滤波去尖峰 + 物理量程截断后的标准数据集。
- `labels/loop_labels.json` & `labels/loop_labels.csv`：全量回路元数据、真实机理参数与异常标签。

## 4. 数据字段说明
| 字段名 | 类型 | 单位/范围 | 说明 |
| :--- | :--- | :--- | :--- |
| `timestamp_s` | float | s | 相对采样时间戳（0–599 s） |
| `loop_id` | string | — | 脱敏回路唯一编号（`LOOP-001`–`LOOP-030`） |
| `tag_name` | string | — | 标准化位号（如 `TIC-201`） |
| `sp` | float | 工程单位 | 设定值 (Setpoint) |
| `pv` | float | 工程单位 | 过程测量值 (Process Variable) |
| `op` | float | % (0–100) | 控制器输出 / 阀位指令 (Controller Output) |
| `err` | float | 工程单位 | 控制偏差 `SP - PV` |

## 5. 数据安全与脱敏声明
1. 本数据集完全基于工业机理模型（FOPDT + Choudhury 粘滞模型）仿真生成，**不包含任何真实石化企业的厂区名称、装置涉密工艺配方、真实 DCS IP/OPC 地址或人员隐私信息**。
2. 所有位号与时间戳均采用标准化虚拟编码，满足国家人工智能应用中试基地数据脱敏与合规开源要求。
