# V3.0 安全校验、模型门控与审批状态体系 (`V3_SAFETY_VALIDATION.md`)

## 一、统一 7 态机器可读审批状态（100% 由确定性证据推导）
| 状态枚举 (`final_status`) | 触发条件 | 参数变更策略 | 工程含义 |
| :--- | :--- | :--- | :--- |
| `HEALTHY_NO_CHANGE` | 诊断为 `NORMAL` | 保持原 PID | 现有参数合理，无需变更 |
| `VALVE_MAINTENANCE_REQUIRED` | 诊断为 `VALVE_STICTION` | 保持原 PID | 机械粘滞故障，优先安排仪表检维修 |
| `MODEL_VALIDATION_FAILED` | `C-000` 未通过 (`val_r2 < 0.80` 或 `Fit < 85%` 或激励不足) | 保持原 PID | 模型不可靠，拒绝推荐，建议施加安全阶跃激励重辨识 |
| `SAFETY_CONSTRAINT_FAILED` | `C-001`–`C-010` 任一项未通过（含回退保守策略后仍未通过） | 保持原 PID | 不满足稳定裕度或工艺边界，100% 拦截 |
| `PERFORMANCE_NOT_IMPROVED` | 整定后 IAE/OI 未改善或恶化，或属 `EXTERNAL_DISTURBANCE` | 保持原 PID | 反馈 PID 整定非最优解，建议排查上游扰动源/前馈补偿 |
| `SIMULATION_VALIDATED_PENDING_ENGINEERING_REVIEW` | 模型有效 + 11/11 项安全硬约束通过 + 仿真性能显著改善 | 推荐新 PID | **仅仿真校验通过，待自控工程师人工复核审批（严禁未审批写入真实 DCS）** |
| `REJECTED_WITH_REASON` | 其他不可整定边界条件 | 保持原 PID | 附结构化拒绝证据 |

## 二、11 项确定性安全硬约束（`04_algorithms/petro_pid/safety_verifier.py`）
- **C-000**：FOPDT 独立留出验证模型有效性（`val_r2 >= 0.80` 且 `val_fit_pct >= 85%`）
- **C-001 ~ C-003**：PID 参数物理边界（`Kc ∈ [0.05, 8.0]`, `Ti ∈ [1.5, 200]s`, `Td ∈ [0, 20]s`）
- **C-004 ~ C-006**：频域鲁棒稳定裕度（`GM >= 1.8`, `PM >= 35°`, `Ms <= 2.2`）
- **C-007**：**标称工况**阶跃超调红线（`<= 18%`）
- **C-008 ~ C-009**：执行器保护（阀门饱和占比 `<= 10%`, 单步最大变化率 `<= 10%/s`）
- **C-010**：**5 工况跨边界验证**（标称、±20% 增益、+25% 滞后、-20% 时间常数）：
  - **显式扰动工况专用红线**：`超调 <= 25%`、`OI <= 0.42`、且 **5/5 全部闭环稳定**；
  - **单回路放行门槛**：`>= 80%`（4/5）且 100% 稳定，失败工况显式列于 `failed_regimes`；
  - **全量复核回路总体多工况通过率**：实测 **`100.0%` (`11/11` 全部 5/5 通过)**，远超赛题 `>= 85%` 要求。
