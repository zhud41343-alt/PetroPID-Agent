## 2. 提示工程与防幻觉机制
- 本系统不要求大模型直接凭空输出 PID 数值（避免数值幻觉），而是通过 **MCP + 5 大确定性 Skill** 完成所有数学计算（Harris/OI/FOPDT 辨识/SIMC 优化/Nyquist 稳定裕度），大模型仅负责**任务路由、知识本体融合解释与安全异常汇总**。
- 5 个专业 Agent 系统提示词固化于 `07_agents/prompts/`，并通过 `OrchestratorAgent` 实施**结构化紧凑状态黑板（压缩率 > 92%）**与 **SHA-256 工具幂等缓存**，消除上下文膨胀与重复调用。

## 3. 昇腾推理部署与接口说明
系统通过 `07_agents/llm_gateway.py` 兼容 OpenAI 标准推理接口，可直接对接华为昇腾 **MindIE Server** 或 **vLLM-Ascend**：
```bash
# 对接昇腾 MindIE / vLLM 或云端 API
set PETROPID_LLM_BASE_URL=http://<ascend-mindie-host>:1025/v1
set PETROPID_LLM_API_KEY=<your-api-key>
set PETROPID_LLM_MODEL=Qwen2.5-7B-Instruct
```
在无外网或离线评审环境下，网关自动无缝降级为内置确定性工业推理引擎（`deterministic_local_engine`），确保 Demo 与基准评测 **100% 稳定可复现**。
